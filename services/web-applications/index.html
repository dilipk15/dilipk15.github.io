FAQ

Questions about custom web applications

Why not just use off-the-shelf software?

Often you should, and I'll say so if a ready-made tool fits. A custom application makes sense when your process is different enough that you keep working around the software, or when you're paying for several tools to do one job.

How long does a web application take?

A focused first version usually takes 4 to 8 weeks. Larger systems are built in stages, so you start using the most important part early.

Who hosts it, and who owns it?

It's hosted in an account you own, and you own the code and data. I help set up hosting and explain the monthly running costs up front.

Can we start small?

Yes, and it's usually the best way. We build the part that saves the most time first, then add to it once your team is using it.

Have a process that eats up your week?

Tell me about it. I reply within one working day, and the first call is free.
